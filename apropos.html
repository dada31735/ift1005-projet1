À propos

Public cible

Toutes personnes qui sont intéréssés par la civilisation extraterrestre des Nomais du jeu. Le jeu raconte leur histoire de manière non-linéaire et donc ce site peut éclaircir les détails qu'un joueur aurait pu manquer lors de leur parcours du jeu.

Respect des principes de conception Web

Respect des 4 principes principaux

  1. Répétition : On utilise une palette de couleur qu'on avait généré à partir d'une photo de l'image de la couverture du jeu avec l'outil Image Picker de Coolors.co qu'on a ensuite ajusté pour un meilleur contraste. Vous pouvez observez cela à travers chaque page. Chaque couleure représente quelque chose de specifique :
    • le bleu pâle sert pour indiquer les liens dans le text
    • le jaune sert pour le titre et les éléments structurels
    • l'orange est utilisé pour tout le contenu principal
    • le mauve foncé est utilisée comme couleure de fond
  2. Contraste : entre l'arrière plan et le texte est suffisant. Ceci a était vérifier avec le verificateur en ligne WebAim.
  3. Proximité : dans chaque page il y a une séparation logique des différents éléments et chaque image est positionné à côté du text auquel elle est relié.
  4. Alignement : toute le text est aligné à gauche et chaque page est concue pour un sense de lecture en z.

Respect des meilleures pratiques en conception graphique

Toutes les images sur ce site utilisent le chargement différé et contiennent un text descriptif.
L'extrait de code si-dessous montre cela : 

index.html:
        <img src="images/Carte_du_systeme.png" 
        alt="Image du système solaire" 
        loading="lazy">

        nomai.html:
        <img src="images/Solanum.webp" 
        alt="Portrait de Solanum" 
        loading="lazy">

        projetsabliere.html:
        <img src="images/Sun_station.webp" 
        alt="Station Solaire orbitant le Soleil" 
        loading="lazy">

Chaque image ne contient pas de contenu essentiel à la compréhension de la page et pourrait être enlever sans que la page perd son sens. Comme vous pouvez voir sur cette même page, pour la navigation, nous utilisons du text stylisé par du css et non des images ce qui adhère au meilleures pratique de conception graphique.
