À propos

Public cible

Toutes les personnes qui s'intéressent à la civilisation extraterrestre des Nomais du jeu. Le jeu raconte leur histoire de manière non linéaire. Ce site permet donc d'éclaircir certains détails qu'un joueur aurait pu manquer au cours de son exploration.

Respect des principes de conception Web

Respect des quatre principes principaux

  1. Répétition : Nous utilisons une palette de couleurs générée à partir d'une image de la couverture du jeu à l'aide de l'outil Image Picker de Coolors.co. Nous l'avons ensuite ajustée afin d'obtenir un meilleur contraste. Vous pouvez observer cette palette sur chaque page. Chaque couleur représente un élément spécifique :
    • Le bleu pâle sert à indiquer les liens dans le texte.
    • Le jaune est utilisé pour les titres et les éléments structurels.
    • L'orange est utilisé pour le contenu principal.
    • Le mauve foncé est utilisé comme couleur de fond.
  2. Contraste : Le contraste entre l'arrière-plan et le texte est suffisant. Cela a été vérifié à l'aide de l'outil en ligne WebAim.
  3. Proximité : Chaque page présente une séparation logique entre les différents éléments. De plus, chaque image est positionnée à proximité du texte auquel elle se rapporte.
  4. Alignement : Tout le texte est aligné à gauche et chaque page est conçue pour suivre un sens de lecture en Z.

Respect des meilleures pratiques en conception graphique

Toutes les images de ce site utilisent le chargement différé (lazy loading) et contiennent un texte descriptif. L'extrait de code ci-dessous en donne quelques exemples : 

index.html:
        <img src="images/Carte_du_systeme.png" 
        alt="Image du système solaire" 
        loading="lazy">

        nomai.html:
        <img src="images/Solanum.webp" 
        alt="Portrait de Solanum" 
        loading="lazy">

        projetsabliere.html:
        <img src="images/Sun_station.webp" 
        alt="Station Solaire orbitant le Soleil" 
        loading="lazy">

Aucune image ne contient d'information essentielle à la compréhension de la page. Elles pourraient donc être retirées sans que celle-ci perde son sens. Comme vous pouvez le constater sur cette même page, nous utilisons du texte stylisé avec CSS plutôt que des images pour la navigation, ce qui respecte les meilleures pratiques en conception graphique.
